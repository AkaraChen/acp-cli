One terminal UI for every coding agent. 一个终端界面，接入所有 coding agent。

acpc runs any Agent Client Protocol agent (Claude, Gemini, OpenCode, Goose, or your own) inside the OpenAI Codex terminal UI. Halfway through a task, hand the conversation to another agent and keep going. acpc 把任何支持 Agent Client Protocol 的 agent（Claude、Gemini、OpenCode、Goose，或者你自己写的）放进 OpenAI Codex 的终端界面里。任务做到一半，可以把整段对话交给另一个 agent 接着做。

Used to Codex? Keep your habits and change the agent. 用惯了 Codex？习惯不用改，换个 agent 就行。

acpc is built from openai/codex at a pinned commit plus a patch series of about 130 KB. The screen, the composer, diffs, approvals and history are Codex's own code, so the keys you know still work. Try Claude, Gemini or OpenCode one session at a time, without learning a new tool first. acpc 基于 openai/codex 的一个固定 commit 构建，上面只叠了大约 130 KB 的补丁。界面、输入框、diff、审批和历史记录都是 Codex 原本的代码，你熟悉的按键照样能用。你可以一次一个会话地试 Claude、Gemini 或 OpenCode，不用先学一个新工具。

Switching agents doesn't mean starting over. 换 agent，不用从头再来。

A complete ACP v1 client, and nothing more. 完整的 ACP v1 客户端，仅此而已。

Zed brings ACP agents into an editor and Toad builds a new terminal UI for them. acpc takes the Codex terminal UI as it is and gives it an ACP backend. It ships no agent and favours none: anything that speaks ACP over stdio works after one acpc add. If you build an agent, acpc is a strict client to test it against. Zed 把 ACP agent 放进编辑器，Toad 为它们做了一个新的终端界面。acpc 直接用 Codex 的终端界面，给它接上 ACP 后端。acpc 不自带 agent，也不偏向任何一家：只要 agent 通过 stdio 说 ACP，一条 acpc add 就能用。如果你在写 agent，acpc 是一个严格的客户端，可以拿来测试。

How it works 工作原理

The Codex TUI already talks to its backend through the app-server protocol. acpc gives it a backend that translates that protocol into ACP: a thread is an agent session, a turn is a prompt, and session updates become messages, plans, tool calls and diffs. Codex TUI 本来就通过 app-server 协议和后端通信。acpc 给它换了一个后端，把这套协议翻译成 ACP：thread 对应 agent 会话，turn 对应一次 prompt，会话更新变成消息、计划、工具调用和 diff。

acpc app-server exposes the same bridge on stdio, so tools built to drive Codex can drive any ACP agent. acpc app-server 把同一个 bridge 暴露在 stdio 上，原本驱动 Codex 的工具也能驱动任何 ACP agent。
