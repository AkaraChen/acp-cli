One terminal UI for every coding agent. 一个终端界面，接入所有 coding agent。

acpc runs any Agent Client Protocol agent (Claude, Gemini, OpenCode, Goose, or your own) inside the OpenAI Codex terminal UI. Halfway through a task, hand the conversation to another agent and keep going. acpc 把任何支持 Agent Client Protocol 的 agent（Claude、Gemini、OpenCode、Goose，或者你自己写的）放进 OpenAI Codex 的终端界面里。任务做到一半，可以把整段对话交给另一个 agent 接着做。

Any ACP agent is one command away. 任何 ACP agent，一条命令接入。

acpc ships no agent and favours none. acpc add takes the command that starts an agent in ACP mode. No telemetry, no local transcripts, and acpc never touches your credentials. acpc 不自带 agent，也不偏向任何一家。acpc add 接收启动 agent ACP 模式的命令。没有遥测，不存本地记录，也从不碰你的凭证。

Commands to add ACP agents接入 ACP agent 的命令
Agent Needs前提 Command命令

npx and uvx agents are fetched on first run. The rest must already be installed and on your PATH; follow the agent's link to install it. Your own agent: acpc add ./my-agent. npx 和 uvx 的 agent 首次运行时自动下载。其余的需要先安装好并在 PATH 里，点 agent 名字去它的主页安装。你自己的 agent：acpc add ./my-agent。

Writing an agent? acpc is a strict client to test against. It implements the client side of ACP v1: sessions (new, load, resume, list, close, delete), permission requests with the agent's own options, elicitation forms, config options and modes, available commands, sign-in and cancellation. acpc app-server also lets tools built to drive Codex drive your agent. 在写 agent？acpc 是一个严格的客户端，可以拿来测试。它实现了 ACP v1 的客户端部分：会话（new、load、resume、list、close、delete）、带 agent 自定义选项的权限请求、elicitation 表单、配置项和模式、可用命令、登录和取消。acpc app-server 还能让原本驱动 Codex 的工具来驱动你的 agent。

Install and start 安装并开始用

Install the latest release, add an agent and start. Other options are in the README. 安装最新版本，接入一个 agent，然后启动。其他方式见 README。
