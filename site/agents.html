acpc ships no agent and favours none. acpc add takes the command that starts an agent in ACP mode. No telemetry, no local transcripts, and acpc never touches your credentials. acpc 不自带 agent，也不偏向任何一家。acpc add 接收启动 agent ACP 模式的命令。没有遥测，不存本地记录，也从不碰你的凭证。

npx and uvx agents are fetched on first run. The rest must already be installed and on your PATH; follow the agent's link to install it. Your own agent: acpc add ./my-agent. npx 和 uvx 的 agent 首次运行时自动下载。其余的需要先安装好并在 PATH 里，点 agent 名字去它的主页安装。你自己的 agent：acpc add ./my-agent。
